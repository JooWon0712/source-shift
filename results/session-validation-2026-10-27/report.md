# 세션 기반 파일럿 실행·검증

실행일: 2026-10-27 (Asia/Seoul). 종류: `session-integration`.

후속 확인: 초기 도구 응답에 없던 모델 설정과 생성기 20개의 토큰 사용량을 로컬 로그에서 복원했다. [사용량 추가 관측](usage-recovery.md)을 확인한다. 최초 측정 시점의 `summary.json`은 그대로 보존하며 실제 청구액과 순수 모델 요청 시간은 여전히 미관측이다.

현재 세션의 모델 설정을 상속한 독립 에이전트가 과제 10개를 C/WAT로 생성했다. 공개 실패만 수정에 사용하고 모든 생성·수정이 끝난 뒤 각 시도를 비공개 입력으로 사후 채점했다.

| 과제 | C 최초/최종 | WAT 최초/최종 | C/WAT 수정 횟수 | 비공개 입력 수 |
| --- | --- | --- | --- | --- |
| P01 세 정수의 합 | passed / passed | passed / passed | 0 / 0 | 71 |
| P02 세 정수의 최댓값 | passed / passed | passed / passed | 0 / 0 | 74 |
| P03 범위 제한 | passed / passed | passed / passed | 0 / 0 | 76 |
| P04 절댓값 | passed / passed | passed / passed | 0 / 0 | 70 |
| P05 부호 판정 | passed / passed | passed / passed | 0 / 0 | 70 |
| P06 0부터 n까지 정수 합 | passed / passed | passed / passed | 0 / 0 | 71 |
| P07 팩토리얼 | passed / passed | passed / passed | 0 / 0 | 10 |
| P08 최대공약수 | passed / passed | passed / passed | 0 / 0 | 77 |
| P09 십진수 자릿수 | passed / passed | passed / passed | 0 / 0 | 83 |
| P10 소수 판정 | passed / passed | passed / passed | 0 / 0 | 82 |

각 경로의 공개 입력은 30개, 비공개 입력은 684개다. 상세 판정·크기·단계별 시간·모든 시도의 본문과 공개 프롬프트는 [summary.json](summary.json)에 연결했다.

## 해석 범위

- 세션 에이전트의 공개 응답 파일을 평가했다. 초기 도구 응답에는 API 원 응답/모델 설정/seed/출력 토큰 상한/usage/요청 지연이 없었다. 후속 로그에서 모델 별칭·추론 설정·usage를 복원했으며 백엔드 snapshot과 순수 요청 지연은 미관측이다.
- 생성기는 문맥을 새로 시작하며 공개 명세와 예제만 전달받았다. 각 과제·경로 1회이고 공개 실패 시 최대 2회 수정한다.
- 초기 공개 검사와 생성·수정 종료 후 사후 평가에서 각각 컴파일한다. 두 단계 시간은 별도로 기록한다.
- 시간은 Python 시작/JIT/기록을 포함한 개발 검증 시간이며 실행 성능 벤치마크나 모델 생성 속도 비교가 아니다.
- 파일 크기는 관측했지만 토큰 수나 비용으로 환산하지 않았다. 본 실행으로 경로의 일반적 우월성을 판단하지 않는다.
- 원본 prompt는 로컬에 보존하고, 공개 복사본의 workspace 절대 경로만 <workspace>로 치환했다.
- 최초 3개는 과제 프롬프트를 직접 전달했고 이후에는 지정한 과제 프롬프트 파일만 읽도록 했다. 추가 전달 지시문도 함께 보존했다.
- dispatch.txt는 실제 발송 지시문과 대조해 재구성한 기록이며 공급자 원 응답이나 전체 system/developer 문맥은 아니다.
- 이번 20개 응답은 UTF-8/바이트 상한을 지켰다. 현재 보조 스크립트는 응답 인코딩·크기 위반 시 원본을 보존하고 중단하므로 해당 실패의 자동 집계는 후속 보완 사항이다.

## 관측한 경로별 합계

| 경로 | 최초/최종 통과 과제 | 공개 입력 | 비공개 입력 | 수정 호출 | 본문 합계(bytes) | Wasm 합계(bytes) |
| --- | --- | --- | --- | --- | --- | --- |
| C | 10 / 10 | 30 / 30 | 684 / 684 | 0 | 729 | 3981 |
| WAT | 10 / 10 | 30 / 30 | 684 / 684 | 0 | 2022 | 962 |

본문 크기는 생성한 함수 본문의 UTF-8 바이트를 합산한 값이다. Wasm 크기에는 템플릿, 컴파일러 메타데이터와 최적화 차이가 반영될 수 있다. 이 수치를 토큰·비용·실행 성능으로 환산하지 않는다. 최초 공개 검사 60건은 위 사후 평가 1,428건과 별도로 수행했다.

이 합계표는 summary.json의 원시 집계 필드에서 보고서 작성 단계에 산출했다.
